# Brambab's Portfolio

This is a personal portfolio website showcasing my projects, certificates, and CV.

## Files

- `index.html` – portfolio homepage
- `style.css` – styling
- `script.js` – interactive behavior
- `documents/` – CV and certificates
- `images/` – portfolio images

## Run locally

Open `index.html` in a browser, or serve the project with a local web server such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

You can publish this site using GitHub Pages by enabling Pages in the repository settings and selecting the main branch.
